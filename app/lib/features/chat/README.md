## Entry points for other features

- **Community (DMs / inbox):** `DirectMessageScreen(userId:, userName:, userAvatar:, onBack:)` opens a direct
  conversation (full screen, above the shell, hides the nav while open). `ConversationListScreen(onBack:, onOpenChat:,
  partnerId:, onOpenGroup:)` is the inbox; `MessagesScreen(onBack:, partnerProfileId:)` / `MessagesHost(onBack:)` the
  whole Messages flow (list → DM / partner chat / group). `ref.read(shellProvider.notifier).openMotherChat()` shows it
  as the shell overlay.
- **Groups (`social.groups`):** reuse `ConversationScreen(kind: ChatKind.group, target: groupId, title:, subtitle:,
  onDetails:, canModerate:, readOnly:)` for `GroupChatScreen`, `ChatMemberPicker` for creation / invitations, and
  override `chatGroupScreenProvider` (`(context, groupId, onBack) => GroupChatScreen(...)`) so Messages opens real
  groups. Keep the `chat-groups-v3` key of `chatGroupsQuery` (or override `chatGroupsProvider`) when porting the full
  `useChatGroups`.
- **Comments (`social.comments`):** `StickerPicker(onPick:, onClose:)`, `StickerImage(id:)`, `stickerFromImageUrl`,
  `stickerStoragePath`.
- **Partner features:** `partnerMessagesProvider` (`messages`, `unreadCount`, `sendMessage`, `sendLoveToPartner`,
  `markAsRead`; pass `toast: (t) => showChatToast(context, t)`), `sendPartnerMessage(backend, push, actor, partner,
  content)`, `unreadMessagesProvider`.
- **AI chat (`tab.ai`):** `chatMediaObjectPath`, `signChatMediaUrl`, `ChatMediaSrc`.

## Behaviour notes

- The conversation is drawn through an `OverlayPortal` over the whole app (React `createPortal` to `body`, z-80) and
  holds a `fullScreenChatLeasesProvider` lease; Android back closes photo → profile → message menu → the chat.
- The list is reversed (offset 0 = newest): it stays pinned to the bottom and keeps the position when older pages load
  (React restored `scrollTop` by hand). A new message from the peer while scrolled up shows the "Yeni mesajlar · n" pill.
- The message menu keeps its inline space (invisible copy) and is drawn above the dimming backdrop with a
  `CompositedTransformFollower` (CSS z-index 5 over the fixed z-4 backdrop).
- `visibilitychange` (mark-read, recording cancel) = app resume / hide / pause.
- Stickers need `app/assets/stickers/NN.webp` (`node app/lib/features/chat/copy/gen_chat_copy.mjs --assets`) and the
  `assets/stickers/` pubspec entry; without them the picker cells and sent stickers render empty boxes.
