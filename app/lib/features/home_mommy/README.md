# Mommy home + baby care core (`features/home_mommy`, `features/baby`, `features/recovery`)

Entry point: `registerHomeMommyFeature(FeatureRegistry r)` (`register_home_mommy.dart`) — registers the
mommy stage body (`registerHomeStageBody(LifeStages.mommy, …)` → `MommyDashboard`) and an invisible frame
overlay `pending-timer-stops` (`PendingTimerStopsHost`). The shared home top bar should render
`buildMommyTopBarAction(context)` (= `<ChildSelector compact />`) for the mommy stage.

| Provider | Default | Wire to |
|---|---|---|

| `timerNotificationSchedulerProvider` | no-op | central local-notification scheduler (`notifyNow`, `cancelLocalNotificationIds`) |
| `timerNativeHooksProvider` (state) | no-op | `overrideWith((ref) => ref.watch(liveTimerNativeHooksProvider))` |
| `liveTimerIosFailureToastProvider` | null | sonner `toast.error(msg, 8 s)` |
| `pendingTimerStopsHostProvider` | frame overlay | optionally keep watched at app level (Index mounted it for the whole session) |
| `babyCareServicesProvider` | Flutter haptics, no achievements, unlimited `peekRemainingDaily` | `useAchievements.unlockAchievement`, `useSubscription.peekRemainingDaily` |
| `mommyHomeSlotsProvider` | empty slots, PremiumBlurGate = child | IllnessHomeCard ×2, WeaningHomeCard / WeaningFeedingLink, ParentingHomeCard, BooksHomeCarousel, UpcomingAppointments, WaterWidget, AptekHomeCard, PartnerHomeCard, PremiumBlurGate, PremiumModal |

The `mommy-period`, `recovery`, `illness`, `doctor-report`, `books` screens and the `preemie-hub`, `cakes`,
`teething`, `solid-food-guide`, `parenting` tools are opened through `shellProvider` (`openScreen` / `openToolId`).

## Gaps / workarounds in the foundation

* `QueryState.hasData` treats `dataUpdatedAt == 0` as no data after a failed fetch, so React's
  `initialDataUpdatedAt: 0` would drop the offline-cached children; `childrenQuery` uses 1 ms (equally stale).
* No Material `TextField`-free input in design/: `AInput` (EditableText) lives in `widgets/mommy_ui.dart`; the date
  field of the child dialog uses `showDatePicker` (needs Material localizations at the app root).
* Toasts require an `AToastHost` above the home (App.tsx mounts both toasters).

## Visual uncertainties

* Goldens (`test/features/home_mommy/goldens`, 390×844, light/dark/RTL) are self-generated; emoji have no font in
  the test harness (boxes). Compared by eye with `tools/reference-shots/out/detA/390x844/light/az/mommy.tabs__home*.png`:
  hero, today-info, message, period banner, trackers and summary card structure/spacing match; fixed the Azerbaijani
  uppercase (İ). Not compared: dark/RTL references in detail, the crisis sheets, the child dropdown/dialogs.
* `toLocaleTimeString` / `toLocaleDateString` use intl patterns (`localeTimeHm`, `localeDate`), not the WebView's ICU.
* Framer exit animations of AnimatePresence panels are approximated with `AnimatedSize` + fade (300 ms).
* The growth chart tooltip keeps React's RTL anchoring (`inset-inline-start` on an unmirrored SVG).
