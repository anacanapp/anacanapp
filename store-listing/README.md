# Store listing texts (App Store + Google Play), 21 languages

One file per app language: `ios` (name 30, subtitle 30, promotional text 170, keywords 100,
description 4000, what's new) and `android` (title 30, short description 80, full description 4000,
release notes 500). Screenshots: `scripts/store-screenshots/out` (iOS 1290×2796) and `out-android`
(1080×1920 + 1024×500 feature graphic).

- App Store Connect offers no Azerbaijani, Kazakh, Uzbek or Georgian listing locale; those `ios`
  texts are reference copies. Google Play accepts all 21 (az-AZ, kk, uz, ka-GE, ...).
- `pt` is written in Brazilian Portuguese (store locale pt-BR).
- Legal links in descriptions: https://anacan.az/terms and https://anacan.az/privacy.
