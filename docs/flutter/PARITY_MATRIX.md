# Flutter port: parity matrix (tests; no device) | (tests; no device) |

Authoritative inventory of everything the Flutter app (`app/`) must reproduce from the Capacitor consumer app
(`src/`), measured on branch `claude/blissful-sagan-lqhvv9` (HEAD `8e2bac89`, 2026-11-27). Every row starts as `todo`.
Companion files: `DEAD_CODE.md` (what is not ported and why), `DATA_ASSETS.md` (content that becomes assets),
`SERVICES.md` (behavioural specs for the cross-cutting services).

## How this was built (reproducible)

- **Reachability.** An esbuild bundle of `src/main.tsx` with `import.meta.env.VITE_NATIVE_BUILD = "true"`, `MODE=google`
  (dead `VITE_NATIVE_BUILD !== 'true'` branches are folded away exactly as Vite does), following static imports,
  `import()`/`lazy()`, `import.meta.glob(...)` (expanded with fast-glob) and `new Worker(new URL(...))`. TypeScript
  semantics apply: an import whose binding is never used is elided, so such files count as unreachable.
  Result: 2 044 reachable files. The **consumer graph** is the same walk with the web-only routes cut
  (`AdminPanel.tsx`, `moderation/ModeratorPanel.tsx`, `pages/{AdminPage,AdmobAdminPage,ModeratorPage,PartnerPage,
  MiniGamesPage,RevenueCatDebug}.tsx`, `public-blog/BlogPage.tsx`): 1 852 files. Rows cover the consumer graph only.
- **LOC** = `wc -l` of the row's listed files **plus the files it exclusively owns** (a file reachable only through
  that row's roots and not itself another row's root). Shared modules are listed as their own rows (e.g.
  `core.shared-misc`, `home.data-hooks`), so every consumer-graph code file is counted exactly once (0 unassigned).
  `src/data/**` and JSON are excluded from LOC (see `DATA_ASSETS.md`); CSS is counted only in `core.design-tokens`;
  native rows count Kotlin/Java/Swift, `patches/` and `packages/` sources.
- **Depends on** is extracted from the row's files and the hooks/libs they import directly: `pkg:` npm packages
  and Capacitor plugins (`X(plugin)` = `registerPlugin('X')` custom plugin), `fn:` edge functions
  (`functions.invoke` / `/functions/v1/…`), `rpc:` Postgres RPCs, `hooks:`/`lib:` app modules (ubiquitous ones such as
  `tr`, `i18n`, `userStore`, `useAuth`, `use-toast` omitted), `data:` `src/data/<dir>`. `+N` = N more not shown.
  `fn:`/`rpc:` list every name referenced in the scanned files, so a shared helper can add names the unit does not
  call (e.g. `tab.cakes` lists book functions because it uses `lib/books/api.ts#openExternal`); treat them as a superset.
- **Stage/role**: `flow`/`bump`/`mommy` = life stage, `partner` = partner shell, `!partner` = women only,
  `all` = everyone, `linked` = only with a linked partner, `AZ` = Azerbaijan country/language gate, `admin`/`moderator`
  = role, `cfg` = tile visibility comes from `tool_configs.life_stages` / `*_active` at runtime (not hard-coded;
  `code tool` = id in `src/lib/code-tools.ts`). Row ids map to `Index.tsx` ids: `tab.<tab>`, `screen.<activeScreen>`,
  `tool.<ToolsHub id>` (merged sections per `src/lib/merged-tools.ts`).
