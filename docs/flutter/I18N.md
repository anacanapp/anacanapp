# Flutter i18n: runtime spec and port

Source of truth: the React code (`src/lib/i18n.ts`, `tr.ts`, `app-languages.ts`, `ui-copy.ts`, `startup-i18n.ts`,
`content-i18n.ts`, `content-packs.ts`, `date-utils.ts`, `count-format.ts`, `langDetect.ts`, `geoLanguage.ts`,
`scripts/i18n/inline-localization.mjs`, `scripts/i18n/content-packs.mjs`, `scripts/i18n/content-translation-core.mjs`).
Where docs and code disagree, this file follows the code (see "Deviations" at the end).

Flutter port: `app/lib/core/i18n/` and `app/lib/core/content_packs/`. Export tool: `app/tool/i18n/export.mjs`.

## 1. Languages

- 25 bundled languages, order of `APP_LANGUAGES`: az en tr ru de ar ka kk uz zh id fr es pt vi hi ja ko pl nl sv ky et tk uk.
  Each has `code`, English `name`, `native_name`, `locale` tag (`az-AZ`, `en-US`, …, `ar` without region, `zh-CN`,
  `pt-PT`, `ky-KG`, `tk-TM`, `uk-UA`) and `flag`.
- `NEW_LANGUAGE_CODES` (16, the content-pack languages): zh id fr es pt vi hi ja ko pl nl sv ky et tk uk.
  `LANGUAGE_EXPANSION_21` = vi hi ja ko pl nl sv, `_23` = ky et, `_25` = tk uk (the 11 "count unit" languages).
- Website/brand portal: 21 languages (without ky et tk uk).
- RTL: only `ar` (`RTL_LANGS`). The web sets `<html dir lang>` before the first render.
- `normalizeAppLanguage(v)`: string → trim → lower-case → `_`→`-` → primary subtag; unknown → `az`.
- `resolveAppLanguages(remote)`: remote `app_languages` rows for bundled codes are forced `is_active: true` (remote order,
  remote names, remote `disabled_tools`); bundled languages missing remotely follow in bundle order; for pack languages
  missing remotely `disabled_tools` is copied from the remote `en` row. Unknown remote codes are dropped. Fetch:
  `select code,name,native_name,is_active,sort_order,disabled_tools order by sort_order`; error/empty → bundled list.
- Date locale (`getCurrentDateLocale`, date-fns): en→enUS, zh→zhCN, ky→custom (ru patterns + Intl `ky-KG` names),
  tk→custom (tr patterns + fixed Turkmen names, distances, relative words, ordinal `N-nji/njy`), others → same-named locale,
  default az. Flutter: `AppLanguageInfo.intlLocale` + `ensureDateLocales()` (registers a `tk` intl locale built the same way).

Dart: `app_languages.dart` (+ generated `generated/app_languages.g.dart`), `textDirectionFor`, `materialLocaleFor`
(tk → ru for Material/Cupertino tables, which have no Turkmen).

## 2. Where the language choice lives

| Store | Key | Value | Written by |
|---|---|---|---|
| Capacitor Preferences (native) | `anacan_app_language` | normalized code | `userStore.setLanguage` (native only) |
| Capacitor Preferences | `anacan_has_selected_language` | `"true"`/`"false"` | `setHasSelectedLanguage` |
| localStorage | `language` | code | `setLanguage`, App boot |
| localStorage | `anacan-user-store` | zustand JSON, `state.language` | zustand persist |
| server | `user_preferences.language` | code | LanguageSelector (3 s bounded upsert) |

Startup (`bootstrap-app.tsx`): `Preferences.get('anacan_app_language')` (whole restore bounded to 3 s) → `setLanguage`;
then normalize → `applyDocumentDirection` → `ensureLanguageReady(lang)`. `readAppLanguage()` (used by `tr`) reads the
in-memory value kept by the store; cold fallback: `anacan-user-store`.state.language, then `language`, else `az`.

Flutter: `LanguagePreferenceStore` (`read/write(key)`) is injected; `I18nRuntime.bootstrap()` reads
`anacan_app_language` + `anacan_has_selected_language` with the same 3 s bound, writes back the normalized code, hydrates
the disk cache and merges the bundled dictionary. `languageFromWebStorage(userStoreJson:, languageKey:)` reproduces the
web fallback for the localStorage-migration path. `AppLanguageController.changeLanguage` = LanguageSelector `change`:
`ensureLanguageReady` → `setLanguage` (persists to Preferences) → overlay load. The web then reloads; Flutter rebuilds
widgets watching `appLanguageProvider`. Server upsert of `user_preferences.language` stays with the caller (profile layer).

## 3. UI dictionary (`tr`)

### 3.1 Lookup
- `tr(key, azDefault)` = `translationCache[currentLang][key]`, if `!== undefined`, else `azDefault`. **az also looks up**
  (its cache is `src/locales/az.json`), so an az.json value overrides the inline default.
- `formatTr(key, azDefault, values)`: first `formatCountUnit(lang, azDefault, values)` (11 expansion languages, template
  exactly `{x} <unit>[.]`, numeric finite value → `Intl.NumberFormat(locale,{style:'unit',unit,unitDisplay,maximumFractionDigits:2})`),
  else `tr(...)` with `{name}` (`[A-Za-z_][A-Za-z0-9_]*`) replaced by `String(values[name])` for own keys only; unknown
  placeholders stay.
- `useTranslation().t(key, d)`: `az` → always `d`; else `cache[key] || d` (empty string falls back; `tr` does not).
- `getCachedTranslation(key, lang)` = raw lookup.

### 3.2 Layers and merge order (per language, `translationCache[lang]`)
1. **az**: `src/locales/az.json`, static import, never cached to storage, no DB overlay (all callers skip az).
2. **Disk cache** (non-az boot language only): at module load `localStorage['anacan_i18n_cache:'+lang]` is merged OVER the
   cache, and `anacan_i18n_sig:'+lang` is remembered.
3. **Seed** (`loadLocalSeed`, lazy chunk; en = `src/locales/en.json`, others = `scripts/i18n/<lang>.seed.json`):
   merged UNDER: `{...seed, ...cache}`. Consequence: a dictionary persisted by an older release keeps winning over a newer
   seed for the same key until the DB overlay or a cache clear replaces it.
4. **DB overlay** (`loadTranslations`): `translations` rows `select key, value where lang = :lang`, `range(from, from+999)`,
   pages of **1000** until a page has fewer than 1000 rows. Merged OVER: `{...cache, ...overlay}`. A returned `{error}`
   stops paging, still merges the rows received and leaves the language unloaded (retried next call); a thrown error
   merges nothing. Success marks the language loaded (no further fetch). Concurrent calls share one promise.
   `clearTranslationCache` bumps a generation counter; results of loads started before are discarded.
- `ensureLanguageReady(lang)`: copy chunk + (non-az) `prepareContentLanguage` (not awaited) + seed, then `persistSoon`.
- Callers: boot (`bootstrap-app`), `App` effect on every language (≠ az) → `loadTranslations`; language switch:
  `ensureLanguageReady` before `setLanguage`, then reload.

### 3.3 Cache persistence and signature
- `persistSoon`: coalesced per language, `requestIdleCallback(timeout 5000)` or `setTimeout(1500)`.
- Signature `dictionarySignature(data)`: FNV-1a 32-bit. `h = 0x811c9dc5`; for every key in `for…in` order (array-index
  keys ascending first, then insertion order): `mix(key); mix(String(value))`, where
  `mix(t) { h = imul(h ^ t.length, 16777619); for each UTF-16 unit c: h = imul(h ^ c, 16777619) }`.
  Result `v1:<count>:<(h>>>0).toString(36)>`. If equal to the remembered signature, nothing is written.
- Write: `writeStorageCache` (budget 2 MB of UTF-16 for all disposable caches, 4 MB ceiling incl. essentials; evicts
  lower-priority disposable entries; returns false when it does not fit). The signature key is written only after the
  dictionary write succeeded.
- Flutter: `TranslationStore` + `FileTranslationDiskCache` (`<support>/i18n_cache/anacan_i18n_cache_<lang>.json` and
  `anacan_i18n_sig_<lang>.txt`, temp-file + rename), same merge order, same signature (`dictionarySignature`, verified
  against Node), 1.5 s debounce, `flushPersists()` for app pause. No byte budget (files).

### 3.4 Section copy (`copyText`)
`scripts/i18n/copy/<lang>.json` = `{section: {key: text}}` (sections `redesign` 162, `aptek` 117, `babycare` 258).
`copyText(section, key, lang, vars)` = `own[key] || en[key] || key`, then every `{name}` replaced (split/join) by
`String(value)`. English is in the main bundle, others are chunks loaded by `ensureLanguageReady` and on store changes.
Section helpers: `ap()` (aptek), redesign/babycare wrappers.

### 3.5 Startup copy
`startup-i18n.ts` `COPY[lang][key]` (selectLanguage, selectCountry, searchPlaceholder, noneFound, continue, languageHint,
back, updateRequired, connectionPending, retry; the nine legacy languages only have the last three) → `?? fallback`.
SDK-free, available before any dictionary. Flutter: generated `generated/startup_copy.g.dart`, `startupText()`.

### 3.6 Feature copy modules (not part of the dictionary assets)
`src/lib/*-i18n.ts` / `*-copy.ts` (onboarding, chat, group, appUpdate, premium, blog, regional, weaning, parenting,
qaygicash, consent, paywall-stage, fetal-size, …) each have their own lookup rules (column arrays, `copy.languages`,
DB-overridable `tr` + bundled fallback, content-key bound JSON). They are ported with their features, reusing
`tr`/`copyText`/`contentTranslationKey` from here.

## 4. Build-time inline localization

`inlineLocalizationPlugin` (Vite, `enforce: 'pre'`) runs `analyzeInlineCopy(code, file)` on every module of the build
(`file` relative to the repo root):
- Skipped files: not `src/**.ts(x)`, `*.test.*`, `*.spec.*`, `src/test/`, `src/components/InitialLanguageScreen.tsx`,
  `src/main.tsx`, `src/bootstrap-app.tsx`, `src/brand-portal/`, `src/public-blog/`, `src/website/`, `src/web-entry/`.
  **Admin is not skipped.**
- Extracted: JSX text (React whitespace rules, HTML entities decoded), string literals of display props (`title subtitle
  label description placeholder alt aria-label emptyText emptyMessage buttonText note hint helperText emptyTitle
  searchPlaceholder loadingText errorMessage confirmText cancelText heading`), rendered branches of `?:`, `||`, `??`, `&&`,
  template literals (`a ${x} b` → `a {inline_0} b`, via `formatTr`), first argument of `toast(...)`, `toast.success|error|
  info|warning|message|loading`, `alert`, `confirm`. Not inside `<code> <pre> <style> <script>`. Text must contain a letter
  and not be an invariant token (Anacan, Premium, units, currency codes, language codes…), an identifier-like
  `snake_case`, a URL, e-mail or domain.
- Key: `inline_<basename without .ts/.tsx, lower-cased>_<sha256(utf8(text)).hex[0:12]>` (text trimmed; leading/trailing
  whitespace re-attached outside the call). The key does not contain the directory: same file name + same text in two
  directories share a key.
- Output: `tr(key, text)` / `formatTr(key, text, {inline_0: …})`; `toLocaleString('az'|'az-AZ')` in display context
  becomes `toLocaleString(getLocaleTag())`.
- Values: the inline keys are **not** in `src/locales/az.json` / `en.json`; the seeds of the 16 pack languages contain
  1276–1308 of them; the nine legacy languages none. Missing → the Azerbaijani text (unless the DB overlay has it).

Flutter: `inlineKey(reactFile, azText)`, `trInline(reactFile, azText)`, `formatTrInline(reactFile, template, [values])`
derive the key exactly like the plugin. `app/assets/i18n/_inline_index.json` maps every key →
`{file, azText, placeholders[, files][, admin]}`. Lookup: `node app/tool/i18n/find-key.mjs "<az text>"` (also
`--contains`, `--file X.tsx`, `--key <key>`, `--langs az,en,ru`).

## 5. Content rows (`mapRowTranslation`)

For each field (first non-null/undefined wins):

| Language | Chain |
|---|---|
| az | `f_az`, `f` |
| 16 pack languages | `f_<lang>`, pack translation, (ky, tk: `f_ru`), `f_en`, `f_az`, `f` |
| kk, uz, ka | `f_<lang>`, `f_ru`, `f`, `f_az` |
| de, ar | `f_<lang>`, `f_en`, `f`, `f_az` |
| en, ru, tr | `f_<lang>`, `f`, `f_az` |

If the base `f` is an array and the chosen value a string: `JSON.parse`; on failure split on `\n` (trim, drop empty) when it
contains a newline, else keep the base array. When the pack supplied the value, it is also written to `f_<lang>`
(idempotent re-mapping). Dart: `row_translation.dart`.

### 5.1 Content key
`contentTranslationKey(row, field)` = `${row.id}:${field}:${sha256hex(utf8(canonicalContent([row[f] ?? null,
row[f_az] ?? null, row[f_en] ?? null])))}`; null unless `typeof id` is string or number.
`canonicalContent` = `JSON.stringify` with a replacer that rebuilds every plain object with keys sorted by
`a.localeCompare(b, 'en')` (ICU root collation: punctuation < digits < letters, case-insensitive first, then accents, then
lower before upper). Because `Object.fromEntries` is used, array-index-like keys (`"2"`, `"10"`) still come first in
ascending numeric order. Numbers print as JS `Number#toString`; strings with ES2019 well-formed escaping.
Dart: `content_key.dart` (`canonicalContent`, `compareLocaleEn` from a generated ICU ASCII rank table + Latin/Cyrillic
decomposition, `jsonStringify`, `jsNumberToString`). Proven with real rows of `scripts/i18n/catalog-fixtures.json` whose
keys exist in `scripts/i18n/content/{fr,ja,tk,ky,uk}.json`, and with Node-computed edge cases.

### 5.2 Content packs
- Build (`scripts/i18n/content-packs.mjs`, web builds only; `VITE_NATIVE_BUILD=true` emits nothing, Codemagic also
  deletes `dist/content-packs`, `verify-bundle` fails if packs or content dictionaries are in a native bundle):
  input `scripts/i18n/content/<lang>.json` `{schema:'anacan-content-translations-v1', language, sourceHash, values}`.
  Keys grouped by field (`key.split(':')` second-to-last). Field bytes = Σ(utf8(key) + utf8(JSON.stringify(value)) + 4).
  Field < 32 KiB (target/8) → packed greedily (sorted field order) into `_misc.N` shards of ≤ 256 KiB; otherwise
  `buckets` = smallest power of two ≤ 32 with bytes/buckets ≤ 256 KiB, shard ids `<field>` (1) or `<field>.<i>`;
  bucket = `parseInt(hash[0:8], 16) % buckets`.
- Shard file `<lang>/<id>.<sha256[0:16]>.json`, text = `canonicalJson({schema:'anacan-content-pack-shard-v1', language,
  shard:id, values})`, where `canonicalJson` sorts object keys in **code-unit order** (not localeCompare).
- `<lang>/manifest.json` = `canonicalJson({schema:'anacan-content-pack-manifest-v1', language, sourceHash, keys,
  fields:{field:[shardIds]}, shards:{id:{file, sha256, count, bytes}}})`.
- URL: `https://app.anacan.az/content-packs/<lang>/manifest.json` (native via CapacitorHttp, `Cache-Control: no-cache`,
  15 s) and `/content-packs/<lang>/<file>` (20 s). Gateway: manifest `no-cache`, shards immutable.
- Verification: manifest — schema, language, 64-hex `sourceHash`, shard ids `^[a-z0-9_]+(\.[0-9]+)?$`, files
  `^…\.[a-f0-9]{16}\.json$` starting with `<id>.<sha[0:16]>.`, every field's ids listed. Shard — parse (or accept an
  already-parsed object), recompute `canonicalJson`, sha256 must equal the manifest; schema/language/shard id/values
  checked. The stored text is the canonical text.
- Storage: IndexedDB `anacan-content-packs`, store `kv`: `m:<lang>` (manifest text), `s:<lang>:<id>` (shard text).
  Hot list: localStorage `anacan_content_pack_hot:<lang>` (≤ 64 recently used shard ids, preloaded on `prepare`).
- Runtime: `prepare(lang)` (once): cached manifest → use; revalidate from network unless already revalidated (await only
  if there was no cached manifest); then load hot shards. `lookup(row, field, lang)`: no manifest → remember key (≤ 5000),
  mark missed, start `prepare`, return undefined; else shard for the key; missing/outdated shard → remember hot, request it;
  return the value only from a loaded shard. `requestShard`: cached text served first (an older revision is still served
  while the current downloads — keys bind the exact source); download; hash check; store; notify. Failure backoff per shard
  `min(10 min, 15 s · 2^(n−1))`; a failed download triggers one manifest revalidation (shard may have been replaced);
  manifest failure backoff 30 s. A changed manifest re-requests shards in use and deletes stored shards it no longer lists.
  Listeners fire once per "missed" lookup batch (version counter); `App` re-renders and invalidates queries keyed by the
  current language (300 ms debounce). `retry()` on `online`.
- Fallback until ready: ky/tk → `f_ru`, other pack languages → `f_en` (chain above). First render never waits.
- Flutter: `ContentPackLoader` (same algorithm), `FilePackStore` (`<application support>/content-packs/`, one file per
  URI-encoded key, temp + rename), `httpFetchPack` (package:http), `ContentTranslations` (wiring, version notifier,
  `contentTranslationsVersionProvider`), `installContentTranslationRefresh`. Wire `I18nRuntime.prepareContent =
  ContentTranslations.instance!.prepare` at bootstrap and call `retry()` on connectivity regained.

### 5.3 What is bundled in the native build
Bundled: az.json (static), en.json and the 23 other seeds (lazy chunks, offline), ui-copy JSONs, startup copy, feature copy
modules, `premium-copy.json`, `regional-copy.json`, `blog-editorial-copy.json`. Not bundled: the 16 content dictionaries
(~108 MB) — downloaded as packs. az/en/ru/tr/kk/uz/de/ar/ka content comes from DB columns.
Flutter: `app/assets/i18n/<lang>.json` (all 25) + `_inline_index.json` + `_manifest.json`; packs downloaded.

## 6. Formatting

- `formatDateAz(date, includeYear)`: pack languages → `Intl.DateTimeFormat(locale, {day:'numeric', month:'long'[, year]})`
  (UTC when the input is a bare `YYYY-MM-DD` string); others → `` `${d.getDate()} ${tr(month_x)}[ ${year}]` `` (local).
- `formatDateTimeAz`: pack languages → Intl with `hour/minute '2-digit', hour12:false` (local); others →
  `` `${day} ${month}[ ${year}], HH:mm` ``. `formatTimeAz` = `HH:mm`. `formatRelativeDateAz`: same calendar day →
  `${tr('dateutils_today','Bu gün')}, HH:mm`, yesterday → `dateutils_yesterday`, else `formatDateTimeAz`.
- `weekdayLabels(lang)`: Intl short weekdays, Sunday first.
- Flutter has no ICU: `export.mjs` captures from Node's ICU the exact `format()` output as templates
  (`{d} {M} {y}`, month names per variant), short weekdays, number symbols (group, decimal, negative prefix, digits,
  minimum grouping digits, Indian secondary grouping), unit patterns per CLDR plural category, plus goldens; Dart renders
  them (`intl_data.g.dart`). CLDR plural rules for the 11 languages are coded in `cldrPluralCategory`.
- `count-plural.ts` (`formatCount`, `weekOrdinal`, `trimesterOrdinal`) and `recap/numbers.ts` `pluralOf`, `utils.ts`
  `getOrdinal`/`turkmenOrdinalSuffix`: ported in `count_format.dart`.
- `formatDatePattern(date, pattern)`: date-fns-like `format` through `package:intl` with Latin digits and no skeleton
  substitution (intl would turn `EEEE` into stand-alone `cccc`). Call `ensureDateLocales()` once.

## 7. Detection
- `geoLanguage.ts`: `request_geo_country()` RPC (2.5 s), country → language table, unknown → `en` (or the first available).
  Dart: `languageForCountry`, `fetchGeoCountry(rpc)`. `languageForDeviceLocale` is a Flutter-only offline helper (unused
  by the parity flow).
- `langDetect.ts` + `community-language-evidence.ts`: ported verbatim (`lang_detect.dart`); `String.normalize('NFC')` is
  emulated with generated composition pairs (Latin, Cyrillic, Vietnamese); `toLowerCase` keeps JS's `İ → i̇`.

## 8. Export tool and assets

`node app/tool/i18n/export.mjs [--check]` (deterministic; `--check` exits 1 when anything is stale):
- `app/assets/i18n/<lang>.json`: minified, keys sorted. = the seed the runtime merges for that language
  (az: az.json **plus every inline key → its az text**, equal to what `tr(key, text)` returns), plus ui-copy entries
  resolved per language as `@copy.<section>.<key>` → `own || en || key`. Missing keys are not filled with Azerbaijani:
  `tr` returns the caller's `azDefault`, as on the web.
- `_inline_index.json`, `_manifest.json` (per language: keys, missingVsAz, extraVsAz, inlineTranslated, bytes, sha256).
- `app/lib/core/i18n/generated/*.g.dart` (registry, startup copy, ICU data) and test fixtures
  (`app/test/core/i18n/fixtures/golden.json`, `app/test/core/content_packs/fixtures/content_samples.json`).

## 9. Deviations and observations (code vs docs, web vs Flutter)
1. The plugin does not exclude admin files (1944 of 2343 inline keys are admin-only); brand-portal/public-blog/website/
   web-entry are excluded inside `analyzeInlineCopy`, not in `vite.config.ts`.
2. Inline keys are absent from az.json/en.json and from the nine legacy seeds: English and the legacy languages show
   Azerbaijani for inline-extracted text unless the DB overlay provides it.
3. A persisted dictionary beats a newer seed (merge order) — reproduced.
4. `t()` vs `tr()` differ for az and for empty strings — both provided.
5. Two canonical JSON forms: content keys sort object keys with `localeCompare('en')`; packs use code-unit order.
6. Docs list 11 470 UI keys for ky/et; the seeds now have 12 669.
7. Pack-language dates/units depend on the device ICU on the web; Flutter uses the Node ICU snapshot from export time.
   V8's `format()` and `formatToParts()` differ in whitespace (U+202F vs space, e.g. uk `2024 р.`); templates follow `format()`.
8. Overlay rows whose value is not a string are ignored in Flutter (web would store `null`).
9. Flutter's disk cache has no 2 MB budget (files instead of localStorage).
