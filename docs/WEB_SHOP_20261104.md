# anacan.az shop: Kitablar and Tortlar (2026-11-04)

Azerbaijani-only shop pages on the public website, paid with Epoint through the
`web-shop` Google function. Other languages return 404 for these slugs.

## Routes and source
- `/az/kitablar/` (books) and `/az/tortlar/` (cakes); missing trailing slash 301s.
- `src/website/routes.ts`: `SHOP_PAGES`, `SHOP_SLUGS`, `isShopPage`; alternates only for `az`.
- `src/website/Shop.tsx`, `shop-data.ts`, `shop.css`: catalogue (public `book_catalog`,
  `cakes` reads via `gcp.anacan.az`), cart (localStorage), checkout.
- `src/website/seo.ts`: shop titles/descriptions, hreflang `az` + `x-default` only.
- `src/website/components.tsx`: header, mobile menu and footer links shown for `az` only.
- Shop pages are not in `LLM_PAGE_KINDS`, so `llms*.txt` and the manifest are unchanged.
- The earlier patch layer (server.mjs `shopMatch`, `public/website/shop/*`) was removed;
  `scripts/website/server.mjs` equals the live runtime (sha 726a12d…).

## Website source recovery
The latest `src/website` LLM/discovery/brand source was missing from Git and was
recovered from the live unminified renderer: `discovery.ts`, `llm-content.ts`,
`llm-copy.json`, coral brand mark, schema/legal name and footer machine links.
Rebuilt output matches live (llms, robots, sitemaps, 441 LLM documents byte-identical;
only data-driven timestamps differ). See `scripts/website/RUNTIME_DRIFT.md`.

## Payments
- Payment buttons are always visible. While `ENABLE_EPOINT_PAYMENTS` is off the
  function answers 503 `function_disabled`, and checkout shows
  "Ödəniş sistemi hələ aktiv deyil".
- To sell: set Epoint live keys, `ENABLE_EPOINT_PAYMENTS=true` in functions.env
  (recreate functions), and switch `books_payments_enabled` / `cakes_web_payments_enabled`.
- Prices are recomputed on the server; web orders use `channel='web'` with nullable `user_id`
  (migration `20261104210000_web_shop_orders.sql`).
